# MAISON ÉLAN

심플하고 고급스러운 감도의 컨템포러리 여성복 쇼핑몰입니다. 상품 탐색과 상세 정보, 리뷰·문의, 장바구니·주문, Firebase 회원 인증, 마이페이지와 관리자 화면을 포함합니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

## 주요 명령어

- `npm run dev`: 로컬 개발 서버 실행
- `npm run build`: GitHub Pages용 정적 사이트 빌드
- `npm test`: 빌드 및 렌더링 테스트
- `npm run lint`: 코드 검사

## 배포

`main` 브랜치에 변경사항이 올라가면 GitHub Actions가 정적 사이트를 빌드해 GitHub Pages에 자동 배포합니다.
